# MS_project_serum2

Statistical analysis of untargeted serum lipidomics data comparing Clinically
Isolated Syndrome (CIS) with Multiple Sclerosis (MS).

**Report:** https://arikoi.github.io/MS_project_serum2/

## Contents

- `ms_lipidomics_report.qmd` — technical report source

## Data availability

Patient-derived data are not included in this repository. The reports read from
saved result objects that are not distributed here.
